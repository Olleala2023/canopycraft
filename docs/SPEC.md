## 2. Нагрузки

### 2.1 Постоянные (собственный вес)

`g = g_кровля + g_обрешётка + g_стропила + g_прогоны` — кН/м² **по площади ската**.

Справочник кровель (кН/м²):

| Покрытие | g |
|---|---|
| Поликарбонат сотовый 6 мм | 0.013 |
| Поликарбонат сотовый 8 мм | 0.015 |
| Поликарбонат сотовый 10 мм | 0.017 |
| Поликарбонат монолитный 4 мм | 0.048 |
| Профлист С8–С21, 0.5 мм | 0.05 |
| Профлист НС35–Н60, 0.7 мм | 0.08 |
| Металлочерепица | 0.05 |
| Мягкая черепица по OSB-9 | 0.20 |

Собственный вес стропил, обрешётки, прогонов и столбов калькулятор считает сам из
подобранных сечений и включает в нагрузки:

```
дерево   m = b·h·L·n·ρ,   ρ = 500 кг/м³   (сухая сосна; свежераспиленная 700–800)
сталь    m = A·L·n·ρ,     ρ = 7850 кг/м³  (то же, что A[см²]·0,785 кг/м)
кровля   m = g·S/g₀,      g — вес покрытия по скату, S — площадь ската
погонный вес сечения      q = m·g₀ , кН/м — он и идёт в расчётную схему
```

Массы выводятся по группам (кровля, обрешётка, стропила, прогоны, столбы, метизы),
итогом по сосне в м³ и кг, по стали в пог. м и кг, и удельно — кг на м² навеса.
Отдельно показывается доля собственного веса в полной нагрузке: у стены она мала
(снеговой мешок перекрывает всё), в поле заметно больше.

γ_f: сталь 1.05, дерево 1.1, кровля заводская 1.2 (СП 20 табл. 7.1).
Для проверки на отрыв ветром — γ_f = 0.9.

### 2.2 Снег (СП 20 разд. 10)

**Нормативное** значение (п. 10.1): **S = c_e · c_t · μ · S_g**, кН/м² на горизонтальную проекцию.
**Расчётное**: **S_d = γ_f · S**, γ_f = 1,4 (п. 10.12).

⚠ Изменение № 2 перевернуло смысл таблицы 10.1: раньше она давала расчётные значения,
а нормативное получалось умножением на 0,7. Теперь наоборот — в таблице нормативные,
расчётное через γ_f = 1,4. Прогибы считаются на полное нормативное значение.

S_g по снеговым районам (табл. 10.1), кПа — **нормативные**:

| I | II | III | IV | V | VI | VII | VIII |
|---|----|-----|----|---|----|-----|------|
|0.5|1.0 |1.5  |2.0 |2.5|3.0 |3.5  |4.0   |

- `c_e` — снос ветром: 1.0 по умолчанию (для навеса у стены снос не работает — там наоборот намёт).
- `c_t` = 1.0 (холодное покрытие).
- `μ` для односкатного (прил. Б.1): α ≤ 30° → 1.0; 30° < α < 60° → (60−α)/30; α ≥ 60° → 0.

**Снеговой мешок у стены дома — критичный для навеса случай.**
СП 20.13330.2016, приложение Б, схема Б.8, профиль «в» рисунка Б.11 (навес).

```
(Б.5)  μ = 1 + (m₁·l′₁ + m₂·l′₂) / h          h > 8 м → принимается 8 м

«в»    при ширине нижнего покрытия a < 21 м:
       m₂ = 0,5·k₁·k₂·k₃, но не менее 0,1
       k₁ = √(a/21)
       k₂ = 1 − β/35     (при обратном уклоне k₂ = 1)
       k₃ = 1 − φ/30, но не менее 0,3
       m₁ = 0,4 при α ≤ 20°, иначе 0,3; сплошной парапет → m₁ = 0 (прим. 4)
       l′₂ не более утроенной ширины покрытия

«г»    при μ ≤ 2h/S₀:  b = 2h, не более 16 м
       при μ > 2h/S₀:  (Б.6) b = 2h·(μ − 1 + 2m₂)/(2h/S₀ − 1 + 2m₂),
                       но не более 5h и не более 16 м

«д»    потолок μ: 2h/S₀; для навеса 6; для покрытия здания 4 при l′ ≤ 48 м,
       6 при l′ > 72 м, между — интерполяция

«е»    μ₁ = 1 − 2m₂ — без парапетов при b ≥ l′₂ либо при μ ≤ 2h/S₀
       μ₁ = (l′₂ − 0,5·μ·b)/(l′₂ − 0,5·b) — в остальных случаях, не менее 0,2

прим. 3  при h < S₀/2 местную нагрузку у перепада не учитывают
```

**Эпюра** — линейный спад от μ у стены до μ₁ на длине b, дальше μ₁ до конца навеса.
Если `b > l′₂`, до μ₁ эпюра не доходит и на краю навеса остаётся часть мешка.

**Два варианта загружения.** Перечисление «а» требует считать нижнее покрытие дважды:
равномерно (схемы Б.1–Б.7) и с мешком (Б.8). Программа решает оба и берёт огибающую —
у стены правит мешок, в дальней части равномерный снег, потому что μ₁ бывает заметно
меньше единицы.

Для навеса у дома обычно правит ограничение **μ ≤ 2h/S₀**. Смысл геометрический:
в мешок помещается слой снега толщиной h при плотности 2 кН/м³, то есть нормативная
нагрузка у стены равна `2h` кПа и **от снегового района не зависит**.

### Крепление к дому

У стены стоит **второй ряд стальных столбов**, притянутых к газоблоку **сквозными
шпильками** с широкой шайбой-пластиной изнутри. Поверх них лежит **обвязочная доска**
(её часто называют мауэрлатом, но мауэрлат лежит на кладке — здесь это прогон по столбам),
по ней идут стропила.

Что это меняет в расчёте:

- стеновые столбы **раскреплены стеной** по всей высоте → μ = 1,0 вместо 2,0,
  сечение выходит вдвое легче наружных;
- обвязка считается как неразрезная балка на стеновых столбах;
- шпильки проверяются на **смятие газоблока под шайбой** (растяжение от горизонтального
  распора), **смятие газоблока в отверстии** и **срез шпильки**;
- расчётное сопротивление кладки из ячеистых блоков: B2,0 → 0,85; B2,5 → 1,0;
  B3,5 → 1,3 МПа (ориентир по СП 15.13330, уточнять по данным производителя).

**Важно про распор.** Сила тяжести горизонтального распора не создаёт: все опоры
вертикальные, ΣH = 0. Горизонталь даёт только ветер — горизонтальная проекция давления
по нормали к скату плюс напор на наружную кромку. Именно её принимают шпильки; принято,
что плоскость кровли передаёт распор на раскреплённый стеновой ряд.

**Стропило** — наклонная балка. Приведение нагрузок:
```
q_гор  — на горизонтальную проекцию (снег)
q_ск   — на длину по скату (собственный вес)
q_⊥ = q_гор·cos²α + q_ск·cosα     (изгиб)
q_∥ = q_гор·cosα·sinα + q_ск·sinα (осевое сжатие вдоль стропила)
```
→ проверка как **сжато-изгибаемого** элемента.

Схема стропила: балка на 2–3 опорах (стена / промежуточный прогон / прогон по столбам)
**с консолью** на вылет `a`. Опора у стены — шарнир или защемление (выбор пользователя).

**Прогон по столбам** — неразрезная балка на N опорах (столбы) с сосредоточенными силами
от стропил, плюс консоли по краям, если навес выступает за крайние столбы.

**Обрешётка** — неразрезная балка, пролёт = шаг стропил.

**Столб** — сжато-изгибаемый: N от вертикальных нагрузок, M от ветра и от эксцентриситета
опирания прогона.

### Универсальный решатель

Вместо табличных формул — **1D-МКЭ балки Тимошенко** (2 узла × 2 DOF: v, θ; сдвиг учитывается
через GA/κ, κ = 5/6 для прямоугольника). Это даёт:

- любое число и положение опор (пользователь двигает столбы — схема пересобирается),
- любые консоли,
- эпюры M(x), Q(x), v(x) в 100+ точках,
- корректный прогиб коротких деревянных балок (для сосны сдвиг даёт +5…15 % прогиба;
  эквивалент формулы (50) СП 64: f = f₀·[1 + c·(h/l)²]).

Опоры: шарнирная / защемление / упругая (жёсткость k). Нагрузки: равномерная, трапеция
(снеговой мешок), сосредоточенная сила, момент.

Коэффициенты условий работы:
- `m_в` — влажность (табл. 9): класс эксплуатации 2 (под навесом) → 1.0; **класс 3 (открытый
  воздух) → 0.9**; класс 4 → 0.85. Дефолт для навеса: **0.9**.
- `m_т` = 1.0, `m_дл` = 1.0 для сочетаний со снегом (табличные R уже это учитывают);

- `m_н` = 1.2 — только для монтажной сосредоточенной 1 кН.

Проверки:

1. **Изгиб**: `σ = M / W_расч ≤ R_и · m_в · m_дл`, W = b·h²/6 (минус ослабления врубками).
2. **Сжатие с изгибом** (п. 7.17): `N/(A_расч·R_с) + M_д/(W_расч·R_и) ≤ 1`,
   где `M_д = M / ξ`, `ξ = 1 − λ²·N/(3000·A·R_с)` — учёт продольного изгиба.
3. **Скалывание**: `τ = 1.5·Q/(b·h) ≤ R_ск · m_в`.
4. **Устойчивость плоской формы изгиба** (п. 7.4.2): `σ ≤ φ_м · R_и`,

   ⚠ На консоли сжата **нижняя** кромка, где обрешётки нет → l_р = вылет консоли.
   Это реальный риск для длинных свесов — проверка обязательна.
5. **Смятие на опоре**: `σ_см = R_оп/(b·l_оп) ≤ R_см,90`. Определяет минимальную площадку
   опирания стропила на трубу (часто нужна подкладка/оголовок).
6. **Прогиб** (табл. 19, от нормативных нагрузок):
   - стропила, прогоны — `l/200`
   - обрешётка, настил — `l/150`
   - консоль: расчётная длина `l = 2·a`
   Для скатных: предельный прогиб проверяется по нормали к скату.

## 5. Проверки — профильная труба (СП 16.13330.2017)

Стали: С245 R_y = 240 МПа | С255 R_y = 240 (t≤20) | С345 R_y = 315 МПа. R_un = 370/370/470.
R_s = 0.58·R_y. E = 2.06·10⁵ МПа, G = 0.79·10⁵ МПа. γ_c = 1.0 (дефолт), γ_n = 1.0.

Геометрические характеристики — **из таблиц ГОСТ 30245-2003** (JSON-сортамент), а не по
формуле «разность прямоугольников» (та завышает A и I на 3–6 % из-за скруглений — в опасную сторону).

Проверки:

1. **Изгиб** (ф. 41): `M / W_n,min ≤ R_y · γ_c`.
   Опция «учёт пластики» (ф. 42): `M/(c₁·W) ≤ R_y·γ_c`, c₁ ≈ 1.10 для прямоугольных труб — по умолчанию **выключено**.
2. **Косой изгиб** (наклонное стропило из трубы): `M_x/(c_x·W_x) + M_y/(c_y·W_y) ≤ R_y·γ_c`.
3. **Срез** (ф. 44): `τ = Q·S/(I·2t) ≤ R_s·γ_c`.
4. **Прогиб** (СП 20 прил. Д): элементы покрытий `l/200`; эстетико-психологические
   по табл. Д.1 с интерполяцией: l = 1 м → 1/120; 3 м → 1/150; 6 м → 1/200; 12 м → 1/250.
5. **Столб — устойчивость при центральном сжатии** (п. 7.1.3):
   ```
   λ = l_ef / i,   l_ef = μ·l,   λ̄ = λ·√(R_y/E)
   λ̄ ≤ 0.4      →  φ = 1
   0.4 < λ̄ ≤ 3.8 →  δ = 9.87·(1 − α + β·λ̄) + λ̄²
                     φ = 0.5·(δ − √(δ² − 39.48·λ̄²)) / λ̄²
   λ̄ > 3.8      →  φ = 332 / (λ̄²·(51 − λ̄))
   Гнутосварные замкнутые профили — тип кривой «b»: α = 0.04, β = 0.09
   Проверка: N / (φ·A·R_y·γ_c) ≤ 1
   ```
   Коэффициент расчётной длины μ задаётся **отдельно в двух плоскостях**:
   поперёк ряда (x — к дому и от дома; в этой же плоскости действуют ветровой
   распор и эксцентриситет опирания) и вдоль ряда (y — вдоль стены). Условия
   там разные: поперёк верх столба может быть притянут к дому через кровлю,
   вдоль стены рама обычно ничем не держится. Значения: 2.0 (верх свободен),
   1.0 (верх удержан связями от смещения), 0.7 (удержан + защемление внизу).
   Устойчивость проверяется в каждой плоскости своей длиной; гибкость и местная
   устойчивость стенки — по той плоскости, которая правит общей устойчивостью
   (там наибольшая λ и наименьший φ), сжатие с изгибом — по плоскости x.
   ⚠ Вдоль стены навес обычно не раскреплён → μ_y = 2.0, и именно эта проверка,
   а не прочность, определяет сечение столба. Для лёгкого навеса N использует
   несколько процентов несущей способности, а размер стойки диктует норма на
   гибкость. Жёсткий узел (подкос столб–прогон) смещаемость рамы не снимает:
   право на μ = 1.0 даёт только связь, не дающая верху уехать вбок.
6. **Столб — внецентренное сжатие** (п. 9.2.2, ф. 109):
   `N/(φ_e·A·R_y·γ_c) ≤ 1`, φ_e по прил. Д.3 от λ̄ и m_ef = η·m, m = (M/N)·A/W.
   Fallback (консервативно, с предупреждением): `N/(φ·A) + M/W ≤ R_y·γ_c`.
7. **Предельная гибкость**: колонны `λ_u = 180 − 60·α`, α = N/(φ·A·R_y·γ_c) ≥ 0.5;
   второстепенные элементы λ_u = 200.
8. **Местная устойчивость стенки** (табл. 9): `b_ef/t ≤ (1.2 + 0.35·λ̄)·√(E/R_y) ≤ 1.9·√(E/R_y)`.

## 6. Узлы, отрыв, фундамент

### Крепление стропила к опоре (СП 64, разд. 8 и табл. 20)

Считается. Ветер поднимает лёгкую кровлю: при покрытии из профлиста собственный
вес отрыв не перекрывает, и стропило висит на крепеже.

**Схема узла.** Стропило прижато к опоре перфорированным уголком с двух сторон
либо сквозным болтом. Уголок здесь не для жёсткости: он переводит отрыв в **срез**
крепежа — на выдёргивание гвозди и саморезы в несущих узлах работать не должны.

**Усилие.** Равнодействующая отрыва и скатной составляющей в том же сочетании
(0,9·постоянная − ветровой отсос; снега в нём нет). Скатная составляющая доходит
только до нижней опоры — до наружного прогона.

**Несущая способность одного крепежа на один шов**, кН при размерах в см:

```
смятие древесины   T_см = 0,35·c·d     c — глубина защемления
изгиб гвоздя       T_и  = 2,5·d²       при стальной накладке a = 0
изгиб винта        T_и  = 1,6·d²
изгиб болта        T_и  = 1,8·d²
T = min(T_см, T_и)·m_в
```

Слагаемое 0,01·a² (0,02·a² для стальных нагелей) не учитывается: накладка
стальная, толщина крайнего деревянного элемента принята нулевой — это в запас.

**Число крепежей подбирается** с целевым запасом 0,85, минимум два на узел.
Проверяется не оно, а то, **помещается ли** это число в узле по правилам
расстановки (S1 = 15d вдоль волокон и 4d поперёк для гвоздей и саморезов,
7d и 3,5d для стальных нагелей; полка уголка принята 90 мм). Если не помещается —
нужен крепёж крупнее, а не «набить гуще». Для стальной опоры дополнительно
проверяются срез самосверлящего винта и смятие стенки профиля (R_bp = 1,35·R_un).

### Крепление прогона к столбу (СП 16, разд. 14)

Считается. Вертикальную нагрузку вниз держит само опирание, торец в торец, —
узел для неё не нужен. Узел держит то, что пытается снять прогон с оголовка:
ветровой отрыв, горизонтальную силу и, у жёсткого узла, момент от
эксцентриситета опирания.

**Сварной узел** — угловые швы по контуру оголовка, только для стального прогона:

```
A_ш = β·k_f·l_ш,   l_ш = 2(b + h) − 4·10 мм       непровар по 10 мм на каждый из четырёх швов
W_ш = β·k_f·(b·h + h²/3)                          момент сопротивления линии шва
τ   = √( (N_отр/A_ш + M/W_ш)² + (H/A_ш)² )
по металлу шва          β_f = 0,7,  τ ≤ R_wf = 200 МПа (электроды Э46)
по границе сплавления   β_z = 1,0,  τ ≤ R_wz = 0,45·R_un
```

Плюс конструктивное ограничение, которое обычно и оказывается решающим:
`k_f,min (табл. 38) ≤ k_f ≤ 1,2·t_min`. На трубе со стенкой 3 мм это значит
катет не больше 3,6 мм — шов «пожирнее» здесь не помогает, а вредит.

**Болтовой узел** — пластина-оголовок, приваренная на торец столба, прогон на
болтах. Узел в один ряд принят шарнирным: момент от эксцентриситета
воспринимается смятием площадки опирания, болты держат отрыв и сдвиг.

- растяжение болта: `N/n ≤ R_bt·A_bn` (R_bt по табл. Д.5, A_bn — площадь нетто);
- срез болта: `Q/n ≤ R_bs·A`;
- стальной прогон — смятие стенки профиля болтом;
- деревянная обвязка — смятие поперёк волокон под шайбой (σ ≤ R_см90) и работа
  болта как нагеля от горизонтальной силы (табл. 20 СП 64).

К деревянной обвязке приварить нельзя: если выбрана сварка, расчёт считает
болтовой узел и пишет об этом в инспекторе.

### Крепление стеновых столбов к газоблоку

- усилия в сквозных шпильках по эпюре столба как балки на опорах в отметках шпилек;
- смятие газоблока под шайбой-пластиной и в отверстии: σ ≤ 1,2·R_кладки;
- срез шпильки: τ = Q/A_нетто ≤ R_bs.

### Отрыв и фундамент (оценочный блок)

- **Отрыв кровли**: `w_отр · шаг обрешётки · шаг саморезов ≤ несущая способность самореза` →
  выдаём требуемый шаг крепления кровли.
- **Фундамент**: требуемая масса против отрыва наружного столба и сторона
  бетонного куба, дающего эту массу. Основание по грунту не считается.

### Что по узлам ещё не считается

База столба и анкеры в фундаменте. Сварные швы считаются только в узле
«прогон — столб»; остальные соединения конструируются вручную.

**Что где лежит.** Слева — то, что крутят непрерывно: «Геометрия» и «Элементы»
(включая покрытие), а под ними «Крепление к дому». Справа, под инспектором
выбранного элемента, — то, что задают один раз: «Площадка» (снеговой и ветровой
районы, тип местности, параметры снегового мешка — это свойства участка, а не
конструкции), «Материалы» и «Цены»: цены оказываются рядом со стоимостью, к
которой относятся.

Каждый блок сворачивается. По умолчанию открыты «Геометрия» и «Элементы»,
остальные свёрнуты; состояние сохраняется в localStorage и переживает
перезагрузку.

**Тема.** Кнопка в шапке переключает три положения: «как в системе» (по умолчанию),
светлая, тёмная. Палитра целиком на CSS-переменных, так что переключение — это один
атрибут `data-theme` на `<html>`; при «как в системе» атрибута нет и решает
`prefers-color-scheme`. Выбор хранится в localStorage и применяется маленьким
скриптом в `<head>` до первой отрисовки, иначе при тёмной теме мелькает светлый фон.
Печать всегда светлая, какая бы тема ни стояла на экране.

**Справка.** Отдельные страницы в `help/` — статьи о том, что стоит за полями: раскрепление
столбов (μ), снеговой мешок, границы применимости. Ведут туда кнопка «Справка» в шапке и
кружки `?` у полей, к которым статья относится (поле `help` в описании контрола). Страницы
статические, палитру берут из общих токенов через собираемый `help/help.css`.

### Карта нагрузок

Каждый элемент окрашивается по **коэффициенту использования** U = max(всех проверок):

| U | цвет | смысл |
|---|---|---|
| < 0.5 | синий | большой запас, можно уменьшить сечение |
| 0.5–0.85 | зелёный | норма |
| 0.85–1.0 | жёлтый | на пределе |
| > 1.0 | красный | **не проходит** |

Плюс:
- **тепловая заливка поля кровли** по прогибу — сразу видно, где провисает;
- **штриховка зоны снегового мешка** у стены — объясняет, почему там красное;
- наведение на элемент → тултип с числами (M, Q, f, U по каждой проверке);
- клик → правая панель со всеми проверками и формулами.

### Прямые манипуляции

| Действие | Как |
|---|---|
| Двигать столб | перетаскивание вдоль стены, снап 50 мм, показ пролёта |
| Двигать стропило | перетаскивание, показ шага слева/справа |
| Добавить/убрать стропило | двойной клик / Del |
| «Распределить равномерно» | кнопка |
| Менять вылет, свес, уклон, высоту | перетаскивание размерной линии или ввод числа |
| Undo / Redo | Ctrl+Z / Ctrl+Y |

Пересчёт — на каждое изменение (расчёт занимает миллисекунды, МКЭ на 100 узлов).

### Автоподбор

Кнопка «Подобрать» по каждому элементу и «Подобрать всё»:
- перебор сортамента снизу вверх до U ≤ 1.0 с целевым запасом 0.85;
- отдельно — «подобрать шаг» при фиксированном сечении (что чаще нужно на практике:
  доска 50×200 уже куплена — на каком шаге её класть);
- вывод 2–3 альтернатив с ценой в м³ / кг металла;
- узлы подбираются последними, когда сечения уже известны: каталоги упорядочены
  от простого к сложному (гвозди → саморезы → болты; тонкий шов → толстый →
  пластина с болтами), и берётся первое проходящее исполнение. Порог для узлов —
  1,0, а не общий целевой запас: внутри узла запас уже заложен (число крепежей
  считается с коэффициентом 0,85), а вместимость узла и катет шва дискретны.
  Сначала ищется исполнение с запасом и только потом впритык — узел, набитый до
  последнего гвоздя, не прощает ошибок монтажа.

### Подбор по минимальной стоимости

Кнопка «Минимальная цена» перебирает конструкцию целиком и выдаёт список
вариантов с U ≤ целевого запаса, отсортированный по стоимости материалов.

Полный перебор — десятки тысяч сочетаний. Цепочка почти однонаправленная
(кровля → прогон → столбы), поэтому поиск поэтапный:

1. по каждому числу стропил подбирается сначала обрешётка (её пролёт — шаг
   стропил, сечение стропила на неё не влияет), затем стропило под весом уже
   выбранной обрешётки;
2. несколько самых дешёвых кровельных вариантов идут дальше; для каждого
   наружный и стеновой ряды подбираются порознь (6 + 6 сочетаний вместо 36) —
   они связаны только через кровлю, которая к этому моменту уже посчитана;
3. собранный вариант проверяется целиком: отдельные проверки могли пройти,
   а огибающая — нет.

**Почему перебор снизу, а не двоичный поиск.** Сортамент упорядочен по расходу
материала (внутри материала это и есть порядок по цене: дерево считается по
объёму, металл по массе — и то и другое пропорционально площади сечения).
Несущая способность вдоль этого порядка не монотонна: 40×40×3 дороже 50×50×2,
но хуже её и по W, и по радиусу инерции; у 60×60×3 радиус инерции меньше, чем
у более дешёвой 60×60×2. Двоичный поиск такие «ямы» перешагивает и возвращает
сечение дороже нужного — так столбы у стены выходили 100×100×3 там, где
проходила 60×60×2. Перебор снизу возвращает первое прошедшее, то есть заведомо
самое дешёвое; заведомо слабые сечения (не лучше уже провалившегося ни по
одной характеристике: W, I, i, A_s в обеих плоскостях) пропускаются без счёта.

Чтобы перебор был не дороже двоичного поиска, на этапе опор считается только
сам ряд — балка и стойки под ней (`analyseLineBeam`, `analysePostRow`), а не
вся конструкция; нагрузки от кровли передаёт `supportLoads`, общая с полным
расчётом, — формулы распора не расходятся.

### Отчёт

Печатная форма / PDF: исходные данные, схемы, все проверки с формулами и числами,
спецификация материалов (м³ пиломатериала, кг металла, длины), примечания и ограничения.

## 8. Архитектура

Стек: **TypeScript + Vite + React + SVG**, состояние — zustand, тесты — Vitest.
Никаких тяжёлых 3D/CAD-библиотек: план и разрез — обычный SVG, 3D-изометрия — тоже SVG
(параллельная проекция достаточна). Сборка — статика, работает офлайн и с GitHub Pages.

```
src/
  core/                 ← чистая расчётная логика, без UI, 100 % покрыта тестами
    model.ts            модель навеса (геометрия, элементы, материалы)
    loads.ts            снег, ветер, собственный вес, сочетания
    snowDrift.ts        снеговой мешок у стены
    beam.ts             МКЭ балки Тимошенко: эпюры M, Q, v
    distribute.ts       передача нагрузок по цепочке, грузовые ширины
    timber.ts           проверки по СП 64
    steel.ts            проверки по СП 16
    sections/           сортаменты: gost30245.json, gost8639.json, timber.json
    optimize.ts         автоподбор сечений и шагов
    report.ts           сборка отчёта
  ui/
    Canvas/  Plan.tsx  Section.tsx  Iso.tsx  Diagrams.tsx  HeatMap.tsx
    Panels/  Params.tsx  Checks.tsx  Spec.tsx
    store.ts
```

Ключевое правило: `core/` не знает про React и рендер — его можно прогнать в CLI и в тестах.

### Валидация

- ручные контрольные примеры (балка на 2 опорах, консоль, неразрезная на 3 опорах) —
  сверка МКЭ с точными формулами, допуск 0.1 %;
- 3–4 полных проекта, посчитанных вручную по СП, как end-to-end тесты;
- проверка на вырожденных случаях: шаг стропил 0, консоль > пролёта, уклон 0 и 45°.

## 9. Границы применимости (пишем в отчёт)

Не считаем: двускатные и арочные навесы, ветровые связи и раскосы как расчётную схему
(только как условие μ), снеговые нагрузки на неровных кровлях, огнестойкость,
сварные швы и болтовые соединения по прочности, расчёт основания по грунту,
сейсмику, температурные воздействия.

Результат — инженерная оценка для частного строительства, а не проект,
прошедший экспертизу.
