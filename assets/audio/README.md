# Фоновая музыка

Положите сюда до восьми файлов с именами **`1.mp3`, `2.mp3`, `3.mp3` …** —
кнопка ♪ в шапке будет проигрывать их в случайном порядке по кругу.

- **имена обязательно числами.** Статическая страница не может прочитать
  содержимое папки: на GitHub Pages нет листинга каталога, а при открытии
  `index.html` двойным кликом браузер запрещает и это. Поэтому имена заданы в
  коде списком `1.mp3 … 8.mp3`, и какие из них есть на самом деле, страница
  выясняет при первом включении. Пропуски не страшны: если лежат только
  `1.mp3` и `3.mp3`, остальные вычёркиваются и больше не запрашиваются;
- формат: mp3 — играет везде. Если файл в m4a или ogg, перекодируйте, а не
  переименовывайте: от смены расширения содержимое не меняется;
- размер: разумно до 5–10 МБ на файл. При 128 кбит/с это примерно 1 МБ на
  минуту;
- файлы скачиваются только после нажатия на кнопку — страница не тяжелеет у
  тех, кто музыку не включает;
- репозиторий открытый: кладите только то, на что у вас есть права.

Как положить, не трогая git: на github.com зайдите в эту папку,
**Add file → Upload files**, перетащите файлы, закоммитьте в `main`.

Файлов здесь нет специально — кнопка сама скажет, если не найдёт ни одного.
